### 🚀 Projeto em destaque

**[Finan+](https://github.com/franciscoaciole/controle-financeiro)** — app de controle financeiro pessoal, full stack e em produção.

- **Back-end:** Node.js + Express + Prisma, PostgreSQL (Neon), autenticação JWT
- **Front-end:** React + Vite + Tailwind CSS, responsivo e instalável como app
- **Destaques:** importação de extrato (OFX/CSV) com categorização automática, lançamento em uma linha (`uber 25,90 ontem`), resumo do mês com IA (Gemini), rate limit + helmet, testes automatizados com GitHub Actions

🔗 [Ver online](https://meufinanmais.vercel.app) · [Código](https://github.com/franciscoaciole/controle-financeiro)
